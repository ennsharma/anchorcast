# Anchorcast

A Python client for **real-time media streams generated by pluggable models**.

This is the Completions analog: one `Session`, a `Model` that turns a brief into a clip, a `Source` that decides what to say next, and a generate-ahead buffer. It is not a YouTube app, not a character, and not a news show.

Python first because the runtime talks to generation APIs, ffmpeg, and a disk buffer. A TypeScript client can wait until the later broadcast backend exists.

```python
from pathlib import Path

from anchorcast import Brief, Character, QueueSource, Session
from anchorcast.continuity import IdentityContinuity
from anchorcast.models import H3Max

session = Session(
    model=H3Max(),
    character=Character(
        name="Bear",
        image=Path("bear.png"),
        visual_prompt="Hand-drawn stuffed bear on cream paper.",
        voice_prompt="warm, unhurried cadence",
    ),
    source=QueueSource(),
    workdir=Path(".anchorcast"),
)

session.source.submit(Brief(
    id="rates",
    topic="mortgage rates",
    talking_points=("Why are mortgage rates still high?",),
    citations=("https://example.com/rates",),
    priority=10,
    kind="paid",
))

for event in session.run(max_segments=1):
    print(event.segment.path, event.segment.brief.topic)
```

## Interfaces

- **`Brief`** — the unit of work (topic, talking points, citations, priority, optional payer). Same role as a chat message.
- **`Model`** — `generate(request) -> Segment`. `H3Max` ships first; swap later.
- **`Source`** — `next_brief(playhead) -> Brief | None`.
  - `QueueSource` — explicit/paid briefs
  - `FeedSource` — RSS/Atom/JSON-feed mapped to cited stories
  - `IdleSource` — character bits that make no news claims
- **`Continuity`** — which still starts the next clip (`LastFrameContinuity` or `IdentityContinuity`)
- **`Session`** — fills a small generate-ahead buffer, does not mint clips faster than the playhead

YouTube / Twitch / TikTok Live and Super Chats are a later backend that maps platform events into `Brief`s on a `QueueSource`.
